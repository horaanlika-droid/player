# Catch 22 — приглашение-плеер

Статическая страница без сборки; для хостинга рядом лежит крошечный
Node.js-сервер `index.js` без единой зависимости, который её отдаёт
(см. «Деплой на BotHost»).

Интерфейс собран поверх фото-плеера
`IMG_1468.png`: сгенерированная панель `assets/layers/plate.webp`, поверх неё —
бобины кассеты, бумажная наклейка кассеты с надписью «catch22 / 1st anniversary
invite», набранной крупно и контрастно шрифтом печатной машинки Special Elite,
прозрачные зоны управления и бегущая строка на ЖК-дисплее. Звёздочка возле
логотипа CATCH22 и наклейка с бокалом «1 YEAR! CATCH 22» убраны — правый
верхний угол корпуса остаётся чистым пластиком. Красная лампочка на PLAY мигает
до первого нажатия на клавишу, после чего постоянно горит красным (в том числе
после STOP).
Внизу страницы — неброская подпись `designed by @stonym0ntana`.

Плеер никогда не занимает больше 72% высоты окна, поэтому на iPad и десктопе
вокруг него остаётся фон на весь экран — тот же тёплый оливково-угольный тон
(`#0b0b0a`) и то же матовое зерно, что на тёмных полях фотографии
(`assets/layers/noise.png`, 256×256 RGB со спектром корреляции из фото, генератор
`tools/make_ambient.py`). У самой панели `assets/layers/plate.webp` внешние поля
вокруг силуэта плеера плавно сведены в `alpha = 0`, поэтому прямоугольная
граница кадра 1024×1536 отсутствует, а тень `.device` строится по реальному
корпусу плеера. Фон задаётся на корневом холсте страницы, включая safe area
Safari на iPad. На телефоне в портретной ориентации плеер по-прежнему
масштабируется почти на весь экран.

Клавиша PLAY запускает трек (Gorillaz — «Feel Good Inc.» с лёгкой кассетной
шероховатостью) и анимацию вращения бобин, PAUSE и STOP останавливают.
REW и FF перематывают на три секунды. Текст приглашения отображается на дисплее
точечной ЖК-матрицей: контур букв Handjet заполняется ровной сеткой круглых
оливково-чёрных пикселей, подобранных к цветам корпуса и экрана. Текст также
продублирован скрытым блоком для скринридеров; окно бегущей строки совпадает со
стеклом ЖК-дисплея и у краёв мягко затухает, поэтому буквы не заходят на корпус.
Громкость меняется
перетаскиванием, колесом или стрелками по невидимой зоне шкалы VOLUME справа;
уровень кратко показывается на дисплее. Нижняя инфо-панель убрана. Настройка
reduced motion отключает вращение бобин и бегущую строку.

## Локальный запуск

Node.js-сервер (то же, что крутится на хостинге) — зависимостей нет вообще,
`npm install` ничего не скачивает:

```sh
npm start                        # или: PORT=8080 node index.js
```

Открыть `http://localhost:3000` (порт берётся из `PORT`, по умолчанию 3000).

Для быстрой проверки вёрстки без Node годится и статический сервер:

```sh
python -m http.server 3000 --bind 0.0.0.0
```

## Деплой на BotHost

Репозиторий готов к деплою как есть: в корне лежат `package.json` (скрипт
`npm start` → `node index.js`), точка входа `index.js`, `npm`-чистый
`package-lock.json`, `Dockerfile` и `.nvmrc` (Node 20).

1. GitHub → репозиторий подключён к BotHost, ветка `main` (в ней должны
   оказаться эти файлы — то есть сначала нужно влить PR из рабочей ветки).
2. Создать бота: «Платформа» — Telegram или Discord (код от платформы не
   зависит), «Язык» — **Node.js**, поле **«Главный файл (точка входа)»** можно
   оставить пустым — автодетект BotHost сам выберет `index.js`
   (приоритет: `index.js` → `main.js` → `app.js` → …).
3. «Дополнительные настройки» → включить **«Использовать домен»**, порт
   веб-приложения — **3000**. Код читает `process.env.PORT` и слушает
   `0.0.0.0`, поэтому порт из панели и порт в контейнере всегда совпадают;
   если поменять порт в панели, правки в коде не нужны, но нужен повторный
   деплой.
4. Кастомный `Dockerfile` — по желанию: галочка **«Использовать собственный
   Dockerfile»** в тех же настройках (сборка `node:20-alpine` + `node index.js`).
   Без галочки BotHost сгенерирует образ сам из `package.json`.
5. После деплоя проверить `https://ваш-домен/health` — сервер отвечает
   `{"status":"ok",...}`, это готовый health-check для платформы.
6. Открыть `https://ваш-домен/` — там плеер-приглашение. Для Telegram Mini App
   этот же адрес подставляется в кнопку меню у @BotFather.

Переменные окружения (все опциональные — значения по умолчанию подходят):

| Переменная | По умолчанию | Зачем |
| --- | --- | --- |
| `PORT` | `3000` | порт, который слушает сервер (BotHost передаёт сам) |
| `HOST` | `0.0.0.0` | интерфейс прослушивания; менять не нужно — reverse proxy платформы ходит только на `0.0.0.0`, с `127.0.0.1` будет 502/504 |

### Что делает `index.js`

Помимо отдачи статики (`/`, `/assets/**`, MIME-типы для webp/woff2/mp3):
`/health` для проверки живости, поддержка `Range` (без неё Safari на iPad не
перематывает mp3), `ETag`/`Last-Modified` → `304`, gzip для html/css,
`Cache-Control: immutable` для ссылок с `?v=`, 404-страница в тёмной теме
плеера. Служебное наружу не отдаётся: `.git`, `.env`, `node_modules` и любой
выход за корень репозитория получают 404. По `SIGTERM`/`SIGINT` сервер
закрывается аккуратно, чтобы рестарты контейнера проходили без висящих
соединений.

## Инструменты и зависимости

Растровые скрипты в `tools/` требуют Pillow и numpy, а ретушь панели —
также OpenCV. Это инструменты разработки, сайт работает без Python-пакетов.
Зависимости перечислены в `tools/requirements.txt`; при их отсутствии
скрипты печатают подсказку:

```sh
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements.txt
.venv/bin/python tools/cut_reels.py
.venv/bin/python tools/make_ambient.py
.venv/bin/python tools/clean_plate.py          # обязательно после make_ambient.py
.venv/bin/python tools/make_cassette_audio.py  # сборка кассетного трека assets/hbd.mp3
```

`clean_plate.py` убирает старую бумажную наклейку «I ♥ 22» и звёздочку с
веб-панели `plate.webp`. Повторный запуск `make_ambient.py` заново создаст
панель из исходного фото, поэтому после него нужно снова выполнить
`clean_plate.py`.

## Оформление и ресурсы

- `IMG_1468.png` — исходное фото плеера; из него вырезаны бобины
  (`assets/layers/reel-a.png`, `reel-b.png`, см. `tools/cut_reels.py`),
  а веб-панель с мягкой альфа-маской вокруг корпуса и основанием провода
  сохранена в `assets/layers/plate.webp` (`tools/make_ambient.py`, затем
  `tools/clean_plate.py` для удаления старой наклейки и звёздочки).
- `IMG_1448.jpeg` — фото с листом наклеек; остаётся архивным референсом:
  наклейка с бокалом со страницы убрана, вырезанный спрайт не используется.
- `assets/layers/cord.png` — бесшовный по вертикали RGBA-спрайт (64×256)
  прямого чёрного провода наушников, который выходит ровно по оси штекера
  PHONES (`x = 177`) и продолжается от верхнего края `.device` вверх за
  пределы фона и окна на любом экране (`tools/make_ambient.py`). Полный
  статичный кадр с продлённым вверх фоном и тем же проводом сохранён в
  `IMG_1468_cord.png` (1024×1956).
- `assets/layers/noise.png` — бесшовное матовое зерно 256×256 RGB для продления
  фона вокруг плеера (`tools/make_ambient.py`, тон `#0b0b0a` и спектр зерна
  сняты с верхнего поля фото методом 2D FFT).
- `assets/fonts/handjet-*.woff2` — Handjet для дисплея
  (кириллица + латиница).
- `assets/fonts/special-elite-latin-400-normal.woff2` — Special Elite
  (Apache 2.0, сабсет из `@fontsource/special-elite`) для надписи на бумажной
  наклейке кассеты: две строки, «печатная машинка», жирный оттиск ленты
  за счёт `text-stroke` и фильтра `#print-ink`.
- `assets/fonts/neucha-*.woff2` — Neucha для детской рукописной надписи;
  лицензия SIL OFL находится рядом в `assets/fonts/neucha-OFL.txt`.
- `assets/hbd.mp3` — фоновый трек (Gorillaz — «Feel Good Inc.» с аналоговой
  кассетной обработкой и лёгкой шероховатостью плёнки, `tools/make_cassette_audio.py`);
  при сбое загрузки включается резервный синтезатор (WebAudio).
