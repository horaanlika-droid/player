# Catch 22 — приглашение-плеер

Статическая страница без сборки. Интерфейс собран поверх фото-плеера
`IMG_1468.png`: сгенерированная панель `assets/layers/plate.webp`, поверх неё —
бобины кассеты, бумажная наклейка кассеты с печатной надписью
«catch22 1st anniversary invite», печатное «catch» внутри сердечка на стикере
«I ♥ 22», прозрачные зоны управления, бегущая строка на ЖК-дисплее и индикатор
воспроизведения в виде красной полоски на клавише PLAY.

Плеер никогда не занимает больше 72% высоты окна, поэтому на iPad и десктопе
вокруг него остаётся фон на весь экран — тот же тон и то же зерно, что на чёрных
краях фотографии (`assets/layers/noise.png`, генератор `tools/make_ambient.py`),
с мягкой виньеткой. На телефоне в портретной ориентации плеер по-прежнему
масштабируется почти на весь экран, поля — само чёрное поле фото.

Клавиша PLAY запускает трек и анимацию вращения бобин, PAUSE и STOP останавливают.
REW и FF перематывают на три секунды. Текст приглашения отображается на дисплее
уменьшенным пиксельным шрифтом Handjet и продублирован скрытым блоком для
скринридеров; окно бегущей строки совпадает со стеклом ЖК-дисплея и у краёв
мягко затухает, поэтому буквы не заходят на корпус. Громкость меняется
перетаскиванием, колесом или стрелками по невидимой зоне шкалы VOLUME справа;
уровень кратко показывается на дисплее. Нижняя инфо-панель убрана. Настройка
reduced motion отключает вращение бобин и бегущую строку.

## Локальный запуск

```sh
python -m http.server 3000 --bind 0.0.0.0
```

Открыть `http://localhost:3000`.

## Оформление и ресурсы

- `IMG_1468.png` — исходное фото плеера; из него вырезаны бобины
  (`assets/layers/reel-a.png`, `reel-b.png`, см. `tools/cut_reels.py`),
  а веб-панель сохранена в `assets/layers/plate.webp`.
- `assets/layers/noise.png` — бесшовное зерно для фона вокруг плеера
  (`tools/make_ambient.py`, тон и разброс подобраны по чёрным краям фото).
- `assets/fonts/handjet-*.woff2` — Handjet для дисплея, наклейки кассеты и
  сердечка (кириллица + латиница).
- `assets/fonts/neucha-*.woff2` — Neucha для детской рукописной надписи;
  лицензия SIL OFL находится рядом в `assets/fonts/neucha-OFL.txt`.
- `assets/hbd.mp3` — фоновый трек; при сбое загрузки включается
  резервный синтезатор (WebAudio).
