# Catch 22 — приглашение-плеер

Статическая страница без сборки. Интерфейс собран поверх фото-плеера
`IMG_1468.png`: сгенерированная панель `assets/layers/plate.webp`, поверх неё —
бобины кассеты, аккуратно вырезанные из `IMG_1468.png`
(`assets/layers/reel-a.png`, `reel-b.png`, см. `tools/cut_reels.py`),
прозрачные зоны клавиш транспорта поверх физических кнопок фото,
бегущая строка на ЖК-дисплее и нижняя инфо-панель с датой и местом
по образцу catchinvite.

Клавиша PLAY запускает трек и анимацию вращения бобин (класс
`is-playing` на устройстве), PAUSE и STOP останавливают. REW и FF
перематывают на три секунды. Текст приглашения живёт в бегущей строке
дисплея пиксельным шрифтом Handjet (точечная матрица) и продублирован
скрытым блоком для скринридеров. Громкость меняется перетаскиванием,
колесом или стрелками по шкале VOLUME справа — уровень показывается
маркером на шкале и пиксельной строкой `VOL` на дисплее. Настройка
reduced motion отключает вращение бобин и бегущую строку.

## Локальный запуск

```sh
python -m http.server 3000 --bind 0.0.0.0
```

Открыть `http://localhost:3000`.

## Оформление

- `IMG_1468.png` — исходное фото плеера; из него вырезаны бобины
  (зубчатый хаб, r≈50 px, без внешнего кольца окна) и сделан веб-панель.
- `assets/layers/reel-a.png`, `assets/layers/reel-b.png` — RGBA-спрайты
  бобин с мягкой круглой маской; центры подобраны по 8-лучевой симметрии
  спиц, поэтому вращение не «уводит» хаб с посадочного места.
- `assets/fonts/handjet-*.woff2` — Handjet (пиксельный шрифт бегущей
  строки, кириллица + латиница, OFL); `oswald-*.woff2` — Oswald 700
  для инфо-панели.
- `assets/hbd.mp3` — фоновый трек; при сбое загрузки включается
  резервный синтезатор (WebAudio).
